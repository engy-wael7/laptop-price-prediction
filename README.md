# 💻 Laptop Price Prediction App

An interactive Machine Learning web application built with **Streamlit** to predict laptop prices based on various hardware specifications.

---

## 🌟 Features
* **Interactive UI**: User-friendly interface built using Streamlit.
* **Machine Learning Model**: Regression model trained to accurately estimate prices.
* **Custom Inputs**: Allows users to select specifications such as Brand, RAM, CPU, GPU, Storage, and Operating System.

---

## 🛠️ Tech Stack
* **Python**
* **Pandas & NumPy** (Data Preprocessing)
* **Scikit-Learn** (Machine Learning Model)
* **Streamlit** (Web Application Deployment)
